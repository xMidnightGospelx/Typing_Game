# Typing Game

Welcome to the Typing Game repository! This project includes a variety of typing and interactive games designed to improve your typing skills and provide fun and entertainment.

## Library of Games

### Let's Type
- A typing game where you can test your typing speed while reading fun quotes from Sherlock Holmes.
- [Play Let's Type](https://github.com/xMidnightGospelx/Typing_Game/blob/master/Typing_Game/Pages/Index.cshtml)

### My Toy Box
- An interactive play space where you can drag and drop different toys to create your own stories.
- [Play My Toy Box](https://github.com/xMidnightGospelx/Typing_Game/blob/master/Typing_Game/Pages/ToyBox.cshtml)

### Alien Invasion (Under Construction)
- A retro spaceship game where you fight a massive wave of alien invaders.
- [Play Alien Invasion](https://github.com/xMidnightGospelx/Typing_Game/blob/master/Typing_Game/Pages/SpaceGame.cshtml)

## Technologies Used

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/xMidnightGospelx/Typing_Game.git
   ```
2. Open the solution in your preferred IDE.
3. Build and run the project.
